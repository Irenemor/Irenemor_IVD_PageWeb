# Contexto del Producto
TaskFlow es una aplicación minimalista de tareas diseñada para freelancers que desean gestionar sus tareas de manera eficiente. Se enfoca en la simplicidad, la entrada rápida de tareas y el seguimiento de fechas límite.

## Usuarios Objetivo
- Freelancers que manejan múltiples proyectos
- Usuarios que necesitan una gestión de tareas sin distracciones

## Características Clave
- Creación de tareas con fechas límite
- Priorización de tareas
- Interfaz simple con navegación mínima
